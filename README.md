# 📚 Sistema de Gestión de Biblioteca

Sistema de biblioteca en Java con Maven y JUnit 5.

## 🚀 Características

- Gestión de libros (agregar, buscar, eliminar)
- Gestión de usuarios
- Sistema de préstamos con validaciones
- Cálculo de multas por retraso
- Pruebas unitarias completas

## 🛠️ Tecnologías

- Java 11
- Maven
- JUnit 5

## 📦 Uso

```bash
# Compilar
mvn clean install

# Ejecutar pruebas
mvn test

# Ejecutar aplicación
mvn exec:java -Dexec.mainClass="com.library.Main"
```
